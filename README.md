# 📌 Application Tracker

A modern and fully responsive job application tracking app that helps you manage and monitor your job applications in one place.

🚀 Features
- 📄 Create new job applications
- 🏢 Add company, position, location, and job type
- 🔄 Track application status:
- Ongoing
- Interview
- Accepted
- Rejected
- 📅 View status change dates
- ✏️ Edit applications
- ❌ Delete applications
- 📱 Fully responsive design
- 🔔 Toast notification system
- 🛠️ Tech Stack
- React
- React Router DOM
- Redux Toolkit
- React Redux
- Axios
- JSON Server
- React Toastify
- Day.js
- Sass
- Lucide React
